# Mendes & Ruthes — Gabinete Jurídico

Site institucional em Next.js, com conteúdo em português do Brasil e Tailwind CSS.

## Executar localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000). Para gerar a versão de
produção, execute `npm run build` e depois `npm run start`.

O formulário de contato abre o WhatsApp com a mensagem preenchida para revisão
e envio. Imagens originais estão em `assets/images` e suas cópias públicas em
`public/images`.

# Template Generation Example

This fictional example shows the intended transformation:

```text
Fictional reference URL
  -> source analysis
  -> pattern extraction
  -> reusable template
```

The URL in `source-analysis.yaml` is an example-only address. No website was
crawled, no visual tooling was used, and no external assets, copy, source code,
or identifiers were copied.

`source-analysis.yaml` preserves what was observed, inferred, or unknown.
`template.yaml` converts only reusable patterns into the
`modern-professional-services` template. `design-tokens.yaml` holds abstract
token guidance and confidence metadata.

To generate a new site, combine this template with a new business's website
specification, approved content, brand assets, and legal information. The
result should be a new website, never a clone of the reference.

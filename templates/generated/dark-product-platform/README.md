# Dark Product Platform

This reusable template was created from a **partial public analysis** of
`https://linear.app/` using Web Fetch only. It is not a clone and does not
include source copy, assets, code, brand values, tracking identifiers, or
product-specific data.

## Analysis status

- Reference access: `PARTIAL_ANALYSIS`
- Visual inspection: `VISUAL_ANALYSIS_LIMITED`
- Template confidence: `partial`

The public reference indicated a dark-themed software-product context and
public product, customer-proof, pricing, and editorial paths. Exact visual
values, rendered page hierarchy, navigation behavior, and responsive behavior
were not asserted without browser inspection.

## Template contents

- `source-analysis.yaml`: public observations, inferences, limitations, and
  exclusions.
- `template.yaml`: reusable structure validated by the Template Specification.
- `design-tokens.yaml`: abstract token guidance with confidence and basis.
- `pages/home.yaml`: reusable home-page composition.
- `components/`: portable component contracts.

## Use with a new website request

1. Start with the new business's `website-spec.yaml`.
2. Replace every content, brand, CTA, asset, legal, SEO, and product decision
   with approved information for that business.
3. Use this template only for its general dark product-platform structure and
   patterns.
4. Validate accessibility, responsiveness, SEO, and all new assets before
   implementation.

Do not use this template to reproduce the reference website.
